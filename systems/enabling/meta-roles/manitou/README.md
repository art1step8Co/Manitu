# Маниту

**Тип:** метароль  
**Подсистема:** вспомогательная

Маниту — человек-мониторщик конкретной отрасли. Конкретная роль отличается по отрасли, но инвариант сохраняется.

## Инвариант

`Observe → Select → Relate → Route → Record → Close`

Маниту:

- держит луч внимания на отрасли;
- замечает существенные изменения;
- связывает их с текущей картиной мира;
- маршрутизирует людей, события, знания и запросы;
- не даёт значимому состоянию остаться только в голове или локальном чате;
- завершает день фиксацией дельты во внешней памяти.

## Вечернее закрытие

`наблюдения дня → ΔK → версия → commit → push → проверка доступности → CLOSED`

Незавершённое может остаться. Необозначенное — нет.

## Метароль → роль

`Manitou + IndustryContext → ConcreteRole`

Участник сам конкретизирует метароль под свою отрасль. Это часть проверки трансплантации знания.
