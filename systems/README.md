# Три подсистемы

## Целевая система

Объект преобразования: неизвестное → знание.

## Создающая система

Объект преобразования: человек → создатель.

Ключевой принцип: мандат может опережать знание. Это не автоматически ошибка; часть знания возникает в действии.

## Вспомогательная система

Поддерживает прохождение потоков, состояние, внимание, версии и непрерывность работы.

Метароль Маниту относится к вспомогательной системе.
