# Входы по намерению

Пользователь не обязан сначала изучать всю онтологию.

Минимальные входы:

- `become-manitou/` — попробовать метароль Маниту;
- `make-a-film/` — войти через создание фильма;
- `join-a-project/` — войти в действующий проект;
- `contribute-rule/` — принести правило;
- `contribute-technology/` — принести технологию;
- `understand-theory/` — идти сразу к основаниям.

Каждый путь должен вести к действию раньше, чем к полной теории.
