# Стать Маниту

1. Посмотрите короткий ролик.
2. Выберите отрасль.
3. Опишите, что в ней нужно наблюдать.
4. Опишите источники, людей и маршруты.
5. Составьте свой дневной цикл.
6. Проживите один день.
7. Вечером выгрузите дельту в GitHub.
8. Пришлите ссылку/скриншот: "У нас готов новый Маниту".

Успех — не повторение определения, а создание корректной роли в новом контексте.
