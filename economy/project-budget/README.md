# Минимальные валюты проектного бюджета

Проектный бюджет имеет как минимум четыре координаты:

- **Золото (Au)** — время.
- **Медь (Cu)** — ближние перемещения.
- **Бронза (Br)** — дальние перемещения.
- **Серебро (Ag)** — части результата по технологиям, включённым в экосистему.

Формально:

`Budget_p = (Au_p, Cu_p, Br_p, Ag_p)`

Эфир находится над проектными бюджетами и используется как общая валюта экосистемы.
