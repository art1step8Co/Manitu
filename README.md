# Минимальный корпус знаний v0.1

Цель репозитория — позволить человеку или ИИ продолжить работу без необходимости заново восстанавливать контекст у автора или в старом чате.

Главный критерий качества:

> Новый участник должен уметь понять следующий шаг, выполнить его и передать состояние дальше, не создавая новый информационный хвост.

## Основные слои

- `language/` — машинно-читаемые типы понятий и отношений.
- `theory/` — Теория подвига, математика Духа, сознание.
- `systems/` — целевая, создающая и вспомогательная системы.
- `information-heart/` — версии, ритм смены версий, синхронизация, хвосты.
- `economy/` — минимальная система проектных бюджетов и Эфир как надпроектная валюта.
- `paths/` — входы для людей по намерению.
- `onboarding/` — процедура перехода от информационного хвоста к самостоятельной работе.
- `scenarios/` — сценарии роликов и фильмов. Следующая рабочая зона — сценарии Маниту.

## Инвариант передачи

Работа считается завершённой не в момент получения результата, а когда изменение знания:

1. выделено как дельта;
2. записано во внешнюю память;
3. связано с текущей версией;
4. доступно следующему человеку/агенту;
5. не требует повторного объяснения исходным автором.

## Принцип прогрессивной декомпрессии

Человек должен уметь пользоваться системой до полного изучения онтологии:

`сцена → паттерн → имя → роль → связи → система → онтология`

Глубина распаковки добровольна. Согласованность обязательна.
