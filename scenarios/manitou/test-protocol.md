# Протокол тестирования минимального корпуса

## Тест 1. Узнавание
После одного ролика показать неизвестную отрасль.
Проверка: распознаёт ли человек функцию Маниту.

## Тест 2. Перенос
Попросить спроектировать Маниту для своей отрасли.

## Тест 3. Действие
Попросить прожить один рабочий цикл.

## Тест 4. Закрытие хвоста
Вечером участник должен выделить дельту, зафиксировать её и передать состояние дальше.

## Тест 5. Независимость
Следующий агент/человек получает только GitHub.
Если требуется повторное объяснение автором уже созданного знания, фиксируется информационный хвост.

Ключевые метрики:
- Time to First Correct Action
- Time to Instantiate Meta-role
- Number of Reconstruction Questions
- End-of-Day Tail
- Next-Agent Continuation Success
