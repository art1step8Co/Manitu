# Сценарии Маниту

Следующая рабочая зона репозитория.

Задача: создать 5-минутные ролики, которые дают зрителю не терминологию, а:

`Situation → Invariant → Closure → Next Action`

В конце ролика:
- показать результат сезона/проекта;
- показать, что увиденный человек — один элемент большей согласованной системы;
- дать несколько маршрутов "куда дальше";
- QR-код ведёт на GitHub;
- зритель должен суметь создать своего Маниту без обязательного разговора с автором.

## Проверка семантической кросспродажи

После ролика про Маниту одной отрасли дать зрителю сцену другой отрасли без подписи.

Если он способен самостоятельно сказать "у нас Маниту будет выглядеть вот так", паттерн передан.
